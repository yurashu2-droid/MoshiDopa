# 履歴UIの復帰と明細の独立（2026-09-08）

ユーザーの訂正に合わせ、下部ナビの「履歴」を元の history() に戻した。日付選択、横に操作できる棒グラフ、アプリ別の展開リストは元の実装を利用する。

履歴末尾の「日給・月給明細を作る」から別画面へ進む。期間・モード・任意のINVESTプロジェクトを選択し、通帳画像をプレビューして共有する。明細の期間選択で元の履歴の日付とグラフ位置を変更しない。戻るボタンで元画面へ復帰する。

共有の ReceiptRenderer.render() を画面プレビューと ACTION_SEND の両方が使用する。日付／摘要／金額の罫線表にアプリ名と金額を並べ、最後に合計を表示。SPENDは各行に − 、合計に赤い取り消し線。INVESTにはどちらも使わず、プロジェクト・制作メモを載せる。時間非表示は初期値ON。長い摘要やメモは画像内のスペースに収め、省略時は … を表示する。

既存DB v2のデータは保持。複数プロジェクトの明細を先頭プロジェクトの投資額として表記しないよう修正。明細プレビューのスナップショットと表示設定はActivity再生成用に保存する。
