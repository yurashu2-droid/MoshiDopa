# 自動計測・履歴・ナビ改善

2026-09-07

- 自動計測中の本体は金額ではなく、準備状態・対象アプリを開くボタン・STOPを表示。手動計測の金額は維持。
- 「時給換算」「時給に換算」を画面・通知・画像から除き、場面に合う説明に変更。計算条件と免責は残す。
- 設定先頭に「使い方・初期設定 / オンボーディングを見る」。計測中の再設定は停止してから。
- ユーザー提供の3つのSVGをVectorDrawableへ変換。SVGの負のviewBoxと内側の変換も維持。ナビはアイコン＋短いラベル、選択状態・読み上げ対応。
- 値札は高不透明度のスモークグラデーション＋薄い縁。実際の背景ブラーや屈折ではない。apple-designの読みやすさ・階層の原則を優先したガラス風表現。
- 履歴は日付選択、選択日までの7日間の棒グラフ、アプリ/モード別グループ、個別記録の展開。手動活動は活動名でも分ける。
- 保存単価を使った合算、日付またぎの分割、時給の異なる複数記録の合算をテスト。
- アプリの1日分も共有可能。元の記録を変更せず、共有用の一時的な合算データを生成。時間非表示を初期選択にする。
- 履歴の旧1000件上限を解除。非常に大量の記録に対するDB集計・ページング最適化は今後の課題。
