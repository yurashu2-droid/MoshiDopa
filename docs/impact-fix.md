# 衝突と転がりの修正（2026-09-06）

## 演出

値札に時間相当の商品が当たり、短い赤色の反応を残して端から落ちる。
motion-director の因果・退出設計に従い、停止して寿命で消えることを通常の結末にしない。
落下約0.35秒 → 接触・小さい反発 → 横へ回転移動 → 端から重力で退出。
赤色は40msで立ち上がり360msで戻る。金額は黒のまま。SPENDのみ。
既存の金額閾値、計測、明細、低モーション設定は維持する。

## 修正点

- 初速を105–120dp/sにし、画面の余白側へ投じる。表面に一定の加速を加える方式ではない。
- 回転慣性をサイズの二乗でpx単位へ換算し、接触点の有効質量で摩擦インパルスを計算。
- 右向き移動に対する回転符号を修正。表面の減衰を小さくして勢いを残す。
- 回転による形状高さの変化で支持状態が誤解除されないようにする。
- 接触許容距離の画面密度依存を修正。
- 赤い紙面の最大アルファを26/255から85/255へ上げる。従来もイベント配線は存在しており、欠落と断定しない。
- デバッグ輪郭の二重回転を修正。

厳密な汎用剛体エンジンではなく、既存の輪郭＋上面支持近似を維持した演出用物理。
5.5秒の安全清掃は残すが、通常条件でその前に端から落ちることをテストする。

## 検証

- 単体テスト20件成功。新規テストは全3アイコン×密度1/3×左右の12条件で、反発、衝突通知1回、過大回転なし、寿命前の落下を確認。
- ビルドとlint成功。
- Android計測テスト：金額を繰り返し更新しながら実際の衝突後の紙面色を採取し、赤みの増加を検証。
- 動作フレーム採取とドラッグテスト。最初はAndroid設定画面のオーバーレイ抑止でウィンドウ取得がタイムアウトしたため、テストの前提にホーム移動を追加。
- 画像・録画：`screenshots/impact-fix/`。`impact-peak.png`は実際の衝突時のView描画。
- 実機での体感速度とメーカー独自のオーバーレイ制限は未検証。
